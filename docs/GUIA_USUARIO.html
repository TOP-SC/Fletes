1. Acceso a la aplicación

  1. Estar en la red TOP (oficina o VPN).
  2. Abrir el navegador (Chrome / Edge).
  3. Entrar a: http://10.20.2.166:8501

Si no carga: pedir a IT que revise la VM Fletes y los servicios fletes-api / fletes-ui.

2. Iniciar sesión

  1. Usuario y contraseña (los crea el administrador).
  2. Si fallás varias veces, el usuario puede bloquearse: pedir desbloqueo a un super admin.
  3. Cerrar sesión desde el menú cuando termines (sobre todo en PC compartida).

4. Rutina recomendada del mes (paso a paso)

  1. Tango: exportar por fecha de entrega del mes a controlar → Configuración → Tango → Importar.
  2. Reaplicar reglas (si usaste importación rápida o cambió el tarifario).
  3. Tarifarios: si hay Excel nuevo del mes → cargar → activar → recalcular.
  4. Prefactura Clicpaq: importar Excel del mail → Cruce.
  5. Maestro / Resumen: controlar diferencias, editar casos, exportar.
  6. Cross Alfaro: Actualizar / depositar planillas → Excel de control.
  7. Fletes AMBA (si aplica el período).
  8. Postventa / Liquidación cuando lleguen esos archivos.
  9. Export ARCA desde Dashboard cuando Contabilidad lo pida.
Cada archivo Tango se suma a la base (no pisa lo ya importado). Remito oficial: RAR / R; la X es tránsito.

5. Tango — qué bajar y cómo importar

5.1 En Tango

  • Elegir el mes a controlar.
  • Filtrar y exportar por fecha de entrega (ej. 01/05 → 31/05).
  • Igual para Distribuidora (CD) y Limansky (SA).

5.2 En la app

  1. Configuración → pestaña Tango (principal).
  2. Subir el Exportacion.xlsx.
  3. Opcional: “Importación rápida” si son varios archivos grandes → al final Reaplicar reglas una vez.

Si un mes se bajó antes solo por fecha de pedido, conviene volver a importar ese mes por entrega.

6. Tarifarios

  1. Configuración → Tarifarios.
  2. Cargar el Excel de tarifas (hojas clicpaq, fransof, alfaro, LBO, etc.).
  3. Activar la versión vigente.
  4. Recalcular / Reaplicar reglas para que el Maestro tome los nuevos importes.
Si “Alfaro no actualiza”, casi siempre falta activar el tarifario o reaplicar reglas — no alcanza con solo subir el archivo.

7. Prefactura Clicpaq y cruce

  1. Configuración → Prefactura Clicpaq.
  2. Importar el Excel del mail diario del proveedor.
  3. Ejecutar Cruce (macheo por remito, tolerante a formatos).

Después del cruce, en Maestro deberías ver:

  • ENVIO = número de envío CLP (cuando viene en la prefactura), no el pedido SC.
  • FECHA PRESENTACION de la prefactura (en detalle/export tras el cruce; no ocupa la grilla).
  • Precio neto / diferencias vs costo control.

Si casos viejos no muestran ENVIO/fecha: re-importar esa prefactura y volver a cruzar.

8. Maestro — control operativo

Es la planilla de control: 1 fila ≈ 1 remito/caso (aunque Tango tenga varios artículos).

Qué hacer

  1. Elegir período / quincena / filtros (proveedor, zona, alertas).
  2. Revisar costos, dif, observaciones.
  3. Abrir detalle del caso para editar (obs, Suc./CC, flags, override de costos, proveedor tarifa).
  4. Anular remito si no debe entrar al control (antes “excluir planilla”).
  5. Export Excel del filtro completo (no solo la página visible).

Reglas importantes (feedback ya aplicado)

TemaComportamiento
Multi colchón / conjuntoTarifa × unidades (no 1 sola unidad).
Zonas Catamarca CLPUsa K0 / K1 (ya no CA).
Suc. / CCSucursal Tango + fallback por prefijo de cód. cliente (ej. ML9166 → ML).
Paquetería / accesoriosAviso “revisar costo” (patas, sábanas, etc.).
Retiros postventa valorizablesVuelven a Maestro/Resumen cuando aplica (gtía / autorizados).
Franzof remitosAcepta remitos sin guiones (8–14 dígitos).

9. Resumen — control diario

  • Vista tipo LOG WAMARO por día / canal.
  • Export Excel del día completo (no solo lo de pantalla).

Sirve para el control diario frente a lo facturado por el proveedor.

10. Export ARCA / contable

  1. Ir a Dashboard.
  2. Generar export ARCA (estilo Marcela: asientos por proveedor/mes, columnas provincia, colores).
Validar con Contabilidad/Marcela si el formato les sirve. El nº de comprobante puede ser sintético (CTRL-…) según el circuito.

11. Fletes — AMBA / GBA

  • Módulo separado del interior (Mundo 2).
  • Fleteros locales, km, zonas.
  • Configuración → Fleteros: import desde carpeta LOG en S: o upload manual.

12. Cross Alfaro (seguimiento interior) — paso a paso

Ubicación: Configuración → Cross seguimiento.
Objetivo: traer las planillas de seguimiento Alfaro, cruzarlas con el maestro y armar el Excel de control (facturado vs control + suc / COD CLIENTE).

Idea simple:
1) Pulsar Actualizar desde Drive.
2) Ver cada planilla en verde o rojo.
3) Las verdes ya están. En cada roja: Abrir planilla → descargar Excel → Depositar e impactar.

12.1 Nombres de las planillas

Nombre en la appQué esArchivo en el server
SaltaPlanilla Salta (pública en Drive)cross_salta.xlsx
Rosario FransofRosario (archivo grande)cross_rosario.xlsx
Alfaro — Cross interior 1Cross 1cross_1.xlsx
Alfaro — Salta / Jujuy / TucumánSeguimiento NOA Alfarocross_3.xlsx
Alfaro — CórdobaSeguimiento Córdoba Alfarocross_4.xlsx

12.2 Actualizar (lo automático)

  1. Configuración → Cross seguimiento.
  2. Botón Actualizar desde Drive.
  3. Esperar (Rosario puede tardar).
  4. Revisar verdes / rojos.

Salta, Rosario y Cross interior 1 suelen bajar solas. Salta/Jujuy/Tucumán y Córdoba suelen quedar en rojo porque Drive las tiene solo para el grupo SommierCenter (el server no puede bajarlas solo).

12.3 Completar una planilla en rojo

  1. En la fila roja, clic Abrir planilla (abre Google Sheets con tu usuario).
  2. En Sheets: Archivo → Descargar → Microsoft Excel (.xlsx).
  3. Guardar el archivo en tu PC (Descargas o Escritorio). No intentes guardar directo en una ruta Linux del server.
  4. Volver a la app → en esa misma fila roja → elegir el Excel → Depositar e impactar.
  5. La planilla pasa a verde y el cruce con maestro se actualiza.

12.4 ¿Dónde quedan los archivos en el server?

Todo se concentra en una sola carpeta del servidor de la app:

/opt/fletes/data/cross_inbox

Si depositás desde la app, el archivo va ahí automáticamente.
Si IT copia a mano por SCP, usar esos nombres canónicos (cross_3.xlsx, cross_4.xlsx, etc.).

12.5 Excel de control Cross

  1. Cuando haya registros: Generar Excel de control.
  2. Descargar: columnas de facturado / control / dif / suc / COD CLIENTE.

La app también importa hojas tipo Cross Salta (fecha en col A, remito en B).

Estado actual (24/07/2026): con Actualizar + depositar las rojas, el flujo queda en verde y el macheo impacta. No hace falta que los dueños de las planillas cambien permisos a “Cualquiera con el enlace”.

13. Postventa y Liquidación

  • Postventa: Configuración → importar Excel; reglas por TipoGestion / SubTipo.
  • Liquidación: import del circuito de liquidación cuando corresponda.
  • Retiros valorizables de postventa pueden volver a aparecer en Maestro/Resumen.

14. Dashboard gerencial

  • Costo tarifado, remitos interior, cobertura, desvíos.
  • Provincias en pesos (no solo cantidad).
  • Export ARCA (ver sección 10).

15. Usuarios (solo super administrador)

  1. Configuración → Seguridad y acceso / Usuarios.
  2. Alta, activar/desactivar, restablecer contraseña.

16. Cierre mensual (solo administración)

Operación irreversible sobre el período. Usar solo al cerrar contablemente.
  1. Configuración → Sistema → Cierre mensual.
  2. Confirmar checkbox.
  3. Escribir CIERRE.
  4. Ejecutar. (Opcional: también vaciar tarifarios.)
